# EU Retail Analytics — Power BI Portfolio Project

## 📊 Project Overview

This project is an end-to-end retail analytics solution built with Microsoft Power BI.

The project simulates a European retail business operating across multiple countries, product categories, sales channels, customers, returns, and monthly sales targets.

The goal is to transform messy business data into a clean analytical model and an interactive Power BI dashboard that supports sales, product, customer, returns, and target-performance analysis.

---

## 🎯 Business Objectives

The dashboard was designed to answer key business questions:

- How is overall revenue and profit performing?
- Which European countries generate the most revenue and profit?
- Which products and categories perform best?
- Which customers generate the highest revenue?
- How does revenue vary by sales channel?
- What are the major return reasons?
- Which countries have the highest return quantities?
- How does actual revenue compare with sales targets?
- Where are target variances occurring?
- How does business performance change over time?
